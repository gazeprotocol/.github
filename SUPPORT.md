# Getting help

- **Questions and ideas:** start a discussion in the relevant repository, or in `community` once it opens.
- **Bugs:** open an issue using the bug form.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Never post them publicly.
- **Updates:** follow [@Gaze__Protocol](https://x.com/Gaze__Protocol) and [gazeprotocol.com](https://gazeprotocol.com).

Community chat is coming soon.

Issues are for work on the code and docs. We cannot answer questions about token prices or trading.
