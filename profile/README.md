### Where things are

| Repo | Holds | Status |
| --- | --- | --- |
| [`.github`](https://github.com/gazeprotocol/.github) | Org profile, contribution guides, issue forms | Live |
| `community` | Call agendas, notes, recordings, proposals | Coming |
| `docs` | How the protocol works, for watchers and creators | Coming |
| [`brand`](https://github.com/gazeprotocol/brand) | Logos, colors, type and social art for partners and press | Live |

### Open source

Code opens here repo by repo, as each piece clears review.
Watch this org or follow [@Gaze__Protocol](https://x.com/Gaze__Protocol) to see each one land.

### Community calls

Recordings of every live call go to [YouTube](https://www.youtube.com/@gazeprotocol), in the Community calls playlist.
Agendas and notes will live in `community`, so anyone who missed a call can catch up.

### Contributing and security

Read [CONTRIBUTING](https://github.com/gazeprotocol/.github/blob/main/CONTRIBUTING.md) before opening a pull request.
Report vulnerabilities privately, as described in [SECURITY](https://github.com/gazeprotocol/.github/blob/main/SECURITY.md).
