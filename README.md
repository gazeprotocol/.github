# gazeprotocol/.github

Default community files for every repository in the Gaze Protocol organization.
GitHub uses the files here for any repo that does not have its own.

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The org landing page at github.com/gazeprotocol |
| `assets/` | Banners, social preview and badge mark, rendered from the Gaze style guide |
| `CONTRIBUTING.md` | How to contribute |
| `CODE_OF_CONDUCT.md` | How we treat each other |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to ask questions |
| `ISSUE_TEMPLATE/` | Issue forms |
| `PULL_REQUEST_TEMPLATE.md` | Pull request checklist |

Copy in this org follows the Gaze style guide and passes `gaze_copy_lint.py` before merge.
